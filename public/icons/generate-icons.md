# Icon Generation

Place two PNG files here before deploying:

- `icon-192.png` — 192×192 pixels
- `icon-512.png` — 512×512 pixels

Suggested design: dark navy background (#1a1a2e), gold playing card suit symbols.

You can generate them free at https://favicon.io or use any image editor.
These are required for the PWA install prompt on iOS and Android.
